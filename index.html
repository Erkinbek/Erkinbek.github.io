Free tools for files too big to open

Desktop apps that open, search and edit multi-gigabyte text, log, CSV and JSON files without loading them into memory. Free and open source, for Windows, Linux and macOS.

BigText

Editor for huge text and log files.

Opens a 50 GB file at once, searches at 2.5 GB/s, edits and saves safely, and never freezes. Regex search, file compare, hex view, JSON and CSV views, and a command-line tool. A free alternative to EmEditor and UltraEdit, written in Rust.

Katak

Viewer and editor for huge CSV and TSV files.

Opens 10 GB in 0.2 s, searches at 1 GB/s, filters, sorts, edits and converts without loading the file into RAM. A single native binary, written in Rust.

Katak website GitHub

jsonreshape

Viewer, editor and reshaper for huge JSON files.

Opens JSON and JSON Lines files from 100 MB to several GB: search, filter, sort, edit, split and merge, repair, diff, and export to CSV, XLSX, SQLite or Parquet. Works offline.
